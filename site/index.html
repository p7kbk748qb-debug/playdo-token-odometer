Know what you’re looking at.

A little context makes the numbers more useful.

Does this show every token in my Codex account?

It tracks available local Codex usage records on this PC. Remote sessions, other devices and compressed archives may be missing. Codex writes usage in batches, so updates follow complete records rather than every generated token.

Are the model counts exact?

Model attribution is approximate. The app uses the model recorded in local turn metadata and keeps unattributed usage under Unknown. Model totals reconcile to the selected period’s recorded total.

Is this an API bill or a subscription meter?

Token counts are observations of activity, not a billing statement. Cached input is already part of input. Reported account allowance comes from separate local quota snapshots and can be older than your latest activity.

Where does my data go?

The app stores aggregates and preferences locally in data/live. It does not require an API key or send usage to a server. Keep real databases, diagnostic snapshots and Codex logs out of public issues.

Will it keep running when I close it?

Closing the window keeps tracking in the tray. Double-click the tray icon or reopen the taskbar shortcut to restore the app. Choose Exit from the tray menu to stop it completely. Starting with Windows is optional.

Is it really free and open source?

Yes. The source is available under the MIT license. You can inspect it, build it and contribute improvements. The project is independent and is not affiliated with OpenAI.
