# Portable desktop design

The owner selected a clean instrument panel: charcoal surfaces, crisp typography, cyan signals and amber numerals. This is an operating tool, not a marketing landing page.

## Composition
Use a compact navigation rail and separate Overview, Providers, Appearance and Settings surfaces. Keep the exact total prominent, supporting metrics aligned, and coverage text near the data. Settings must not require scrolling through the theme gallery to reach provider controls.

## Tokens
The default Graphite palette uses #171C23 canvas, #222A34 surface, #F0F3F8 text, #A9B6C6 muted text, #FFBD69 amber, #76D8E5 cyan and #475363 borders. Other presets use their own coordinated semantic palettes. Use 6/8/12/16/22/32 spacing steps. Body text uses the bundled Inter family by default.

## Typography
List all available installed families, prioritizing a broad set of serif, sans, monospace and display choices. Render every font label in its own family. Preset names and numerical previews use their preset font pair. Missing fonts fall back; never download fonts in the background.

## Desktop widgets
Keep Dashboard, Compact, Mini and Tiny. Tiny is number-first, borderless, draggable, and has small hide/expand actions. Use translucency only on the requested widget surface; text remains opaque. Reduced motion overrides count-up animation. No polling animation while hidden.

## Truth and states
Distinguish not detected, unselected, importing, tracking and unavailable. Account allowances are separate from observed tokens. No provider logo or support claim should imply access to web chat or account billing.
